# 注注的國語島

給國小一年級的注音國語小遊戲。每個國字旁邊都有注音，用看圖、排句子、翻牌和短故事練習。

**線上練習：** <https://tienyaoai.github.io/Chi-elementary-courses/>

## 怎麼玩

打開網頁後，注注會先說明怎麼看注音。接著可以選：

- **字卡小屋**：家人、學校、大自然、動物。點一張字卡，聽讀音，蓋一個印章。
- **看圖找字**：看圖選出正確的詞語。選錯可以再想一次。
- **句子排排**：把打散的詞語排成一句話。排好再按「看看對不對」。
- **翻翻記憶**：翻開卡片，把圖和國字配成一對。
- **故事偵探**：先讀短故事，再回答問題。

每一關結束會給一到三顆星星。星星和印章只存在這台裝置的瀏覽器裡，關掉分頁也不會上傳。

不會念的時候，按「聽一聽」。右上角可以關掉音效；語音不受這個開關影響。

## 注音

國字使用 [注音粉圓](https://github.com/ButTaiwan/bpmfvs)（BpmfHuninn）。這個字型用異體選擇符把注音畫在國字右邊，所以畫面上不會再疊一層 HTML 注音。字型載入失敗時，改在字的旁邊顯示注音。

「一」和「不」會跟著下一個字自動變調，例如「一個」的「一」讀ㄧˊ，「一隻」的「一」讀ㄧˋ，「不會」的「不」讀ㄅㄨˊ。變調不越過標點。連詞「和」讀ㄏㄜˊ。破音字在題目裡已經標好讀音，例如「睡覺」的「覺」是ㄐㄧㄠˋ，「爸爸」的第二個「爸」是輕聲。

字型授權是 SIL Open Font License 1.1，全文在 `public/fonts/OFL.txt`，異體選擇符的說明在 `public/fonts/NOTICE.txt`。

## 在自己的電腦跑

需要 Node.js 22。

```bash
npm install
npm run dev
```

瀏覽器打開 <http://localhost:4731>。

```bash
npm run verify   # 檢查每個國字都有注音，以及「一」「不」變調
npm run lint
npm run build    # 產出 dist/
npm run preview  # 預覽打包結果，同樣是 4731
```
