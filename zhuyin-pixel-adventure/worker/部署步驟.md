# 學習冒險島 API（v9.24）部署步驟

Cloudflare Workers + D1（免費方案）。**請先在預覽 Worker 測試**，不要直接上正式站。

## 1. 前置

- 安裝 [Node.js 18+](https://nodejs.org/)
- 登入 Cloudflare：`npx wrangler login`
- 本目錄：`cd zhuyin-pixel-adventure/worker && npm install`

## 2. 建立 D1

```bash
npx wrangler d1 create zhuyin-island-db
```

將輸出的 `database_id` 填入 `wrangler.toml` 的 `database_id = ""`。

套用 schema：

```bash
npx wrangler d1 migrations apply zhuyin-island-db --local   # 本機
npx wrangler d1 migrations apply zhuyin-island-db --remote  # 雲端
```

參考 SQL 亦見 `schema.sql`。

## 3. 管理者密鑰

**不要**寫進程式碼：

```bash
npx wrangler secret put ADMIN_TOKEN
```

## 4. 本機開發

```bash
export ADMIN_TOKEN=你的測試管理密鑰
npm run dev
```

預設 `http://127.0.0.1:8787`。安全測試：

```bash
ADMIN_TOKEN=你的測試管理密鑰 npm run test:security
```

報告：`/opt/cursor/artifacts/v9.24-security-report.json`

## 5. 部署預覽 Worker

```bash
npx wrangler deploy
```

## 6. 前端綁定 API

靜態站（flat zip）在 `index.html` 或部署平台設定：

```html
<script>window.__ISLAND_API__ = "https://你的-worker.workers.dev";</script>
```

留空則僅本機遊玩、排行榜需自行設定 API。

## 7. HTTPS

Worker 拒絕非 HTTPS（本機 / workers.dev 例外）。遊戲只應透過 HTTPS 呼叫 API。

## 8. 管理者操作

- 發布公告：`POST /api/admin/announcement`，Header `X-Admin-Token`
- 刪除公告：`DELETE /api/admin/announcement?id=`
- 重設玩家密碼：`POST /api/admin/reset-password`（JSON：`nickname`, `new_password`）

公告內容輸出已 HTML escape，防 XSS。
